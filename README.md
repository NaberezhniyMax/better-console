# Server Console

SSH / PowerShell консоль на Rust (egui/eframe) с настоящим терминалом (PTY + эмуляция vt100).

## Запуск
    cargo run --release

Windows 10/11: PowerShell работает через ConPTY, для SSH нужен клиент OpenSSH (встроен в систему).
Linux: нужны dev-пакеты libxkbcommon, libwayland, libx11, libgl.

## Использование
- "Подключения": профили - SSH (сервер, порт, пользователь, ключ, доп. параметры вроде -J),
  Windows PowerShell, PowerShell 7, cmd, системная оболочка, своя команда. Пароль SSH вводится в терминале.
- "+ Сеанс": открыть вкладку по профилю. Несколько сеансов одновременно, у каждого свой цвет.
- Клавиатура уходит прямо в терминал. Ctrl+C: копирует выделение, а без выделения прерывает команду.
  Ctrl+V - вставка в терминал и во все текстовые поля, включая команды кнопок. Правый клик в терминале вставляет текст из буфера.
  Выделение мышью, двойной клик - слово, колесо - история.
- "Кнопки": отдельный набор для каждого профиля подключения; можно выбрать профиль или сделать кнопку общей.
  Каждая строка команды отправляется в активный сеанс. Цвет кнопки и текста,
  место (сверху/слева/справа/снизу), горячая клавиша, подтверждение, Enter после строки.
  Макросы в командах: {ctrl+c} {ctrl+d} {enter} {tab} {esc} {up} {down}.
- Правый клик по кнопке: изменить, сдвинуть, переместить, удалить.
- Тема светлая/темная и подсветка вывода (пути, IP, ссылки, ошибки, числа, уровни логов) - в Настройках.
- Настройки хранятся в config.json в папке конфигурации пользователя.
- ICO-иконку можно положить в `assets/app.ico` рядом с проектом или EXE. Окно использует ее автоматически;
  до появления файла отображается встроенная запасная иконка.
