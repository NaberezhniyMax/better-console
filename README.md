# Better Console

Настольная консоль для Windows PowerShell, SSH и других командных оболочек. Поддерживает несколько сеансов, профили подключений, настраиваемые командные кнопки и светлую или тёмную тему.

## Возможности

- Подключения: Windows PowerShell, PowerShell 7 (`pwsh`), `cmd`, системная оболочка, SSH и пользовательская команда.
- Несколько сеансов в отдельных вкладках; каждый сеанс работает в собственном PTY.
- SSH использует системный OpenSSH и учитывает `~/.ssh/config`, ключи и `ssh-agent`. Пароль вводится в терминале и не сохраняется приложением.
- Командные кнопки можно привязать к отдельному подключению или сделать общими. Для кнопок доступны горячие клавиши, цвета, расположение и подтверждение перед запуском.
- Настройки шрифта, размера истории терминала и подсветки вывода.
- Копирование выделения мышью; двойной щелчок выделяет слово.

## Запуск готовой сборки

Установщик не требуется: распакуйте релизный архив и запустите `server-console.exe`. В Windows значок окна, файла приложения и трея встроен в EXE.

## Сборка из исходного кода

Для Windows нужны Rust stable, MSVC Build Tools и Windows SDK.

```powershell
cargo build --release
```

Готовый файл появится здесь:

```text
target\release\server-console.exe
```

Чтобы запустить приложение сразу после сборки:

```powershell
cargo run --release
```

При сборке Windows-версия встраивает `app.ico` из корня проекта в EXE. Не удаляйте этот файл перед сборкой. Для SSH в Windows нужен системный клиент OpenSSH; он обычно доступен как дополнительный компонент Windows 10/11.

Linux: для сборки требуются системные библиотеки разработки `libxkbcommon`, `libwayland`, `libx11` и `libgl`. Значок в системном трее предоставляется Windows-сборкой.

## Первые шаги

1. Откройте **Подключения** и выберите профиль либо создайте новый.
2. Для SSH укажите сервер, порт и пользователя; при необходимости задайте файл ключа и дополнительные параметры OpenSSH.
3. Нажмите **Открыть** или выберите профиль в меню **+ Сеанс**.
4. Для PowerShell 7 укажите профиль `PowerShell 7 (pwsh)` и убедитесь, что `pwsh` установлен и доступен в `PATH`.

Профили SSH запускают системную команду `ssh`. Для собственного клиента укажите путь к нему в **Настройки → Путь к ssh**.

## Работа с терминалом

- Клавиши направляются в активный сеанс.
- `Ctrl+C` копирует выделенный текст; если выделения нет — прерывает текущую команду.
- `Ctrl+V` вставляет содержимое буфера в терминал и текстовые поля, включая редактор командных кнопок. Поддерживается русская раскладка.
- Правый щелчок в терминале вставляет содержимое буфера обмена.
- Колесо мыши прокручивает историю терминала; кнопка **К концу** возвращает к текущему выводу.

## Командные кнопки

На странице **Кнопки** можно создать кнопку и привязать её к профилю подключения. Привязанные кнопки и их горячие клавиши доступны только в сеансах этого профиля; кнопки с областью **Все подключения** доступны в любом сеансе.

Команда может содержать несколько строк: каждая строка отправляется в активный сеанс. Доступны макросы:

```text
{ctrl+c}  {ctrl+d}  {enter}  {tab}  {esc}
{up}      {down}    {left}   {right}
```

Правый щелчок по кнопке открывает меню редактирования, перемещения и удаления. Для опасных команд включите подтверждение перед отправкой.

## Настройки и данные

В настройках доступны светлая и тёмная темы, размер шрифта, объём истории и подсветка путей, IP-адресов, ссылок, ошибок и уровней логов.

Настройки подключений и кнопок хранятся локально в `config.json` в каталоге конфигурации пользователя:

- Windows: `%APPDATA%\server-console\config.json`
- Linux: `$XDG_CONFIG_HOME/server-console/config.json` (если переменная не задана — `~/.config/server-console/config.json`)
